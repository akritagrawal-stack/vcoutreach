Each user needs their own Google Cloud Desktop app OAuth client JSON. No shared client is bundled yet. Create a Desktop OAuth client, enable the Gmail API, configure the consent screen, and add yourself as a test user if required.

Choosing the file copies it privately into this workspace. Connect Gmail opens your system browser for consent to gmail.modify (read, label, draft and send access). Sending still needs the typed confirmations, and TEST mode applies.

Client and token files stay private in data/.gmail_credentials.json and data/.gmail_token.json (mode 0600). Connected means a local refresh token is saved; access is verified when Gmail is used.
